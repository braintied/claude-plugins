# 2026-10-15 · /design 0.4: art direction, image sets, motion, a bar set by real sites

Created 2026-10-15 · Updated 2026-10-15 · Version 1

**Why.** G rejected the Tiffin rehearsal site (0.2) as "basic, looks vibe coded in 5
minutes" and asked for a full harness: art direction for the graphics, the images and
the copy; dynamic pages; a bar set by the sites Braintied already makes. Two surveys
(our own recent sites and the Braintied research corpus) found what the sites people
remember share, and what the skill forbade or left out: a world that fills the whole
page, one signature mechanism, image sets of 8–16 frames used at full size, and
engineered motion. The skill had told every build to stay `css`-only, use one fade per
section, and plan two to four images.

**What changed**
- Stage 1: what the founder already has, the moment a visitor should remember, and
  references saved to `docs/brand/references.json` (websites by URL, anything else as
  an image).
- Stage 2 is now direction *and* art direction: references that each govern one thing,
  a world layer (photographic, film, object, field, typographic), a signature mechanism
  with an instrument and a poster-size invariant, four art-direction blocks (images,
  graphics, motion, copy), and colour ownership.
- Stage 3: a fluid display scale (at least 5× body on desktop); a graphic kit in code.
- Stage 4: the set from one `prompts.json` (shared opening + one brief per frame +
  shared closing), anchor frame first, references for recurring objects, cutouts, phone
  crops, a cost table measured on real bills.
- Stage 5: first screens and a motion plan written before code; engines follow the
  world layer; eight tested motion recipes (`references/recipes/`); `fill-mode:
  backwards`; every pin sets `pinSpacing: true`.
- Stage 6: `shots.mjs` puts every page beside the references at 390 and 1440, light and
  dark, with signals; a costume test; scored art direction; slop banned by name; retake
  verbs; a "raise the ceiling" round after the site passes.
- New: `reference-sites.md`, a shelf of live sites sorted by world layer, each described
  from its own first screen.
- Scripts: `image-set.mjs`, `shots.mjs`, `_image.mjs` (references, transparent
  cutouts, jpeg). `audit-prompt.mjs` pins prompt-craft 3.1.0 and explains pnpm's
  release-age hold.

**Proved on.** Tiffin, same brief, three ways, in
`~/Development/edge-city-rehearsal/tiffin-compare/2026-10-15-tiffin-three-way.html`.
Home page at 1440: first screen that is picture 0% (0.2) → 43% (0.3.2) → 88% (0.4);
largest type ÷ body 4.6× → 9.3× → 12.6×; things that move with scroll 0 → 10 → 34.
Images for the 0.4 run: 11 generations, $0.50. G, on seeing it: "this new website is
much better, but i think we can go even harder." The second pass (scroll clock, poster
1 pm, depth, pinned film) is what the scroll-instrument and depth recipes and the
"raise the ceiling" round came from.

**Found on the way, fixed in the harness**
- GSAP turns pin spacing off when the pinned element's parent is flex; the starter's
  `<main>` is. The film stayed pinned while the next section slid over it.
- flare's "transparent" cutout kept a grey half-transparent halo on about a third of
  its pixels; sunburst with the anchor as reference kept 1%.
- `shots.mjs` counted 0 animations on a GSAP site; it now counts inline-style motion.
- Cost estimates were 1.7× high for big frames; recalibrated on today's bills.

**Not done**
- Motion *inside* the photographs (steam, a moving palm shadow) needs a video model;
  the harness has no public video path yet.
- The starter's Supabase proxy returns 500 for any prefetched `/crm` link before
  Supabase is set up (idea-to-mvp, not this plugin).
